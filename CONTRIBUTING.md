# Contribuir a Huillín

¡Gracias por querer ayudar! 🦦

## Reportar errores o proponer ideas
Abre un [issue](https://github.com/storo/huillin/issues/new/choose) con la plantilla correspondiente. Indica tu sistema operativo y la versión de Huillín.

## Enviar código
1. Haz un fork y crea una rama (`git checkout -b mi-cambio`).
2. Compila y prueba: `cargo build` y `cargo test`.
3. Formatea y revisa: `cargo fmt` y `cargo clippy`.
4. Abre un pull request describiendo qué cambia y por qué.

## Compilar
Consulta la sección «Compilar desde el código fuente» del [README](README.md).

## Buenas prácticas
- Cambios pequeños y enfocados.
- Mensajes de commit claros.
- Se respeta la licencia MIT del proyecto.
